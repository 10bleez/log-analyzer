# CLI-Анализатор журналов событий

## Бизнес-требования
Службе поддержки необходимо быстро находить частые ошибки и их источники в больших журналах событий. Приложение должно обрабатывать файлы построчно, не загружая их целиком в оперативную память.

## Реализованный функционал
- Потоковое чтение файла.
- Фильтрация по временному интервалу, уровню и источнику.
- Подсчет строк, сводки, Top-N кодов ошибок.
- Сохранение в JSON или CSV.
- Обработка пустых и отсутствующих файлов.
- Разделение логики на модули parser, filters, aggregator, output, main.

## Развертывание
1. Создайте venv: python3 -m venv venv
2. Активируйте: source venv/bin/activate
3. Установите зависимости: pip install -r requirements.txt

## Примеры запуска (CLI)
**Пример 1:** Фильтрация по уровню ERROR
python3 main.py --input test_log.log --level ERROR

**Пример 2:** Фильтрация по интервалу
python3 main.py --input test_log.log --from "2023-10-25T10:00:00Z" --to "2023-10-25T10:15:00Z"

**Пример 3:** Сохранение отчета в JSON
python3 main.py --input test_log.log --top 3 --format json --output report.json
